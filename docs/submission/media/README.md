# Three-minute walkthrough

[Watch the MP4](fleet-witness-demo.mp4) · [WebVTT captions](fleet-witness-demo.vtt) · [Provenance and SHA-256](provenance.json)

The 180-second video is an edited sequence of 16 browser states and caption cards,
held for reading. It has burned-in captions and no audio. The format is H.264,
1600 × 900, 25 fps, approximately 2.5 MB. It is distributed separately from the
submission ZIP.

The UI was captured from the running local viewer after actual scenario,
presentation and event selections. The captions and result cards were authored
for the walkthrough; the closing result summary is not a raw terminal recording.
The source replay contains synthetic receipts; their signatures are not keys.
No browser account, private provider trace or credential appears in the media.

This is not a continuous real-time screen recording, a new inference run or a live
cloud dashboard. The finite-check command is a reproduction instruction; depth-six
exploration was not repeated to make this video. The original experiment records
and PDF are unchanged.

artwork at 1280 × 560. The [viewer screenshot](../../assets/fleet-witness-viewer.png)
is an actual 1600 × 1100 browser viewport with the Scripted demo label visible.
