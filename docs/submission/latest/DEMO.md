# Three-minute demo script

Completed: [three-minute captioned MP4](https://github.com/k2jac9/fleet-witness/blob/main/docs/submission/media/fleet-witness-demo.mp4), with [captions and provenance](https://github.com/k2jac9/fleet-witness/tree/main/docs/submission/media). This is an edited sequence of 16 actual browser states and title/result cards, held for reading. It is not a continuous real-time capture or a claim of live dashboard availability. There is no audio or new model run.

The outline below guided the edit; the WebVTT file gives the actual captions and timing.

## 0:00–0:30 — The mission

Show the README hero. “A swarm can agree on a release and still lack the evidence or authority to perform it. Fleet Witness keeps the recommendation, authorization and actual effect separate.”

## 0:30–1:15 — Inspect a scripted trace

Run the offline demo using the evidence guide, then open its loopback viewer. Clearly label the screen “scripted mechanism demonstration.” Select a build-only receipt: it can be authentic while failing to support release safety. Follow the recommendation into the controller outcome and audit event.

## 1:15–1:50 — Time changes authority

Inspect revocation and duplicate execution. “A recommendation can be valid at its snapshot and unauthorized at execution. A duplicate authorized request is a no-op. A release here is a database row.”

## 1:50–2:30 — Show the real-model result

Open Figure 1 in the latest report and the public trial table. “In 80 pairs, the raw condition made 18 invalid approvals. The explicit condition denied everything, including 40 valid cases. That prevents useful release selection. The controller blocked all invalid and revoked attempts.” Do not show private provider records or account balances.

## 2:30–3:00 — Show what can be checked

Show the one-command package verifier and the offline reproduction snippet. Mention the separate historical two-model study and the finite checker. End with the limitations: synthetic tasks, local effects, incomplete historical provenance and no uncontrolled web observation. Link the repository and report.
