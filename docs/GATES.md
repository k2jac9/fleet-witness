budget. The connected Adaption tools expose dataset/training operations, not
account billing or Responses inference. Their estimates cannot answer inference

with 256,000 combined context tokens. The
[Responses reference](https://docs.adaptionlabs.ai/api/python/resources/responses/methods/create)
provides token counts and a maximum-output setting but does not establish the
account-specific worst-case charge and reasoning limit required by ADR-0010.
The [FAQ](https://docs.adaptionlabs.ai/resources/faq/) links terms and privacy;
both linked pages yielded only their title in this check, so their substantive
handling terms remain unverified. No secret or inference request was sent in
this continuation.

A precise provider/account confirmation should identify the organization, model
and effective rate version; whether output usage and its configured limit
include all reasoning; whether any extra charges or minimums apply; and the
account statement/API used to reconcile billed credits by request ID. Retain
private account evidence outside Git and link only a sanitized verification
receipt. Do not manufacture an account-verified flag from a public price table.
